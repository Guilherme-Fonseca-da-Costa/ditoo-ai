## Instalação e primeiro acesso

Veja [as instruções de instalação](docs/instalacao.md). Na primeira inicialização sem contas, abra `/setup` e use o código temporário exibido no console para definir seu administrador. Não existe usuário ou senha padrão. Instalações com contas existentes continuam usando o login normal.
